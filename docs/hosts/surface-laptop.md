# surface-laptop

A Microsoft Surface Pro (Intel), used as the productivity machine. Not used
for gaming. Battery life and suspend matter here.

| | |
|---|---|
| Directory | `modules/hosts/surface-laptop/` |
| Aspect | `nixos.surface-laptop` |
| Imports | [workstation](../features/workstation.md), [ballsten](../users/ballsten.md) |
| Inputs | `nixos-hardware` |
| Build | `just build surface-laptop` |

| File | Contents |

## Hardware

`hardware.nix` imports nixos-hardware's `microsoft-surface-pro-intel`
module. It brings the linux-surface kernel, `iptsd` (touchscreen and pen),
`thermald` and `surface-control`.

The linux-surface kernel isn't in the binary cache. It is built from source
and takes about two hours, so a change to it (or a nixpkgs update that
changes it) is slow to build. When reinstalling, build the system on a
running machine and copy it over (see
[impermanence](../features/impermanence.md#install-or-reinstall-a-host)).

Also set here:

- Intel microcode updates and redistributable firmware.
- `usbhid`, `hid_generic` and `hid_multitouch` in the initrd: the Type
  Cover is a USB HID device and is needed to type the LUKS passphrase.
- `boot.loader.efi.canTouchEfiVariables`.

## Disk

One NVMe disk, selected by its `/dev/disk/by-id/` path in `disk.nix`:

| Partition | Contents |
|---|---|
| ESP, 512M | `/boot` (vfat, `umask=0077`) |
| LUKS (`cryptroot`), rest of the disk | btrfs with `@root`, `@nix`, `@persist` (zstd compression, `noatime`) and `@swap` |

`@swap` holds an 8G swapfile, sized for the 8G of RAM, so the machine can
hibernate. It is inside LUKS, so the hibernate image is encrypted.

How the subvolumes are used is in
[impermanence](../features/impermanence.md#how-it-works). The disk unlocks
with the TPM once enrolled ([secure-boot](../features/secure-boot.md#tpm-unlock)).

## Display

The built-in panel (`eDP-1`) is 2736x1824 at about 267 ppi. `display.nix`
sets Umbriel's scale to 2, giving 1368x912 logical pixels.

## Firmware

To reach the Surface UEFI settings, hold **Volume Up** while powering on.
Secure Boot is under **Security → Secure Boot**; see
[secure-boot](../features/secure-boot.md) for when to turn it off.
