# tiki-rig

A desktop PC: everything surface-laptop has, plus gaming. Windows 11 stays
on its own disk for the occasional game or tool that needs it.

| | |
|---|---|
| Directory | `modules/hosts/tiki-rig/` |
| Aspect | `nixos.tiki-rig` |
| Imports | [workstation](../features/workstation.md), [gaming](../features/gaming.md), [ballsten](../users/ballsten.md) |
| Inputs | None |
| Unfree | `nvidia-x11`, `nvidia-settings` |
| Persists | `/var/lib/OpenRGB`, `~/.config/OpenRGB` |
| Build | `just build tiki-rig` |

## Files

| File | Contents |
|---|---|
| `configuration.nix` | The aspects it imports, hostname, time zone (`Australia/Sydney`) and `system.stateVersion` |

## Hardware

| Component | Detail |
|---|---|
| Board | ASUS ROG Crosshair VIII Hero (Wi-Fi), X570 |
| CPU | AMD Ryzen 7 5800X (8 cores, 16 threads) |
| RAM | 32 GiB |
| GPU | NVIDIA GeForce RTX 3080 12GB |
| NixOS disk | Kingston NV3 1TB |
| Windows disk | WD Black SN750 1TB |
| Network | Intel AX200 Wi-Fi and Bluetooth; Realtek 2.5GbE and Intel I211 Ethernet |
| TPM | AMD fTPM (TPM 2.0) |
| Displays | 2× LG 27GL850, 2560x1440 at 144 Hz |

There's no nixos-hardware module for the board, and the generic
`common-cpu-amd`, `common-gpu-nvidia` and `common-pc-ssd` modules set one
option each, so `hardware.nix` sets those options directly.

### NVIDIA

The open kernel modules from nixpkgs' default `stable` driver branch, with
modesetting (needed by Umbriel) and power management, which saves video
memory across suspend. See [0028](../decisions/0028-nvidia-driver.md).

### Keyboard and the USB switch

The keyboard, mouse, headset, speakers and webcam are on a USB switch shared
with another machine. The keyboard is needed in the initrd only until the
TPM is enrolled, but `usbhid` is listed in `hardware.nix` so the LUKS
prompt always works. `nixos-generate-config` leaves it out when the switch
points elsewhere, so if `_hardware-configuration.nix` is ever regenerated,
do it with the switch pointed at tiki-rig.

### Lighting

OpenRGB's server runs as a system service and drives the AURA LED
controller on the board and the G560 speakers' lighting. Its profiles are
in `/var/lib/OpenRGB`, and the OpenRGB app's own settings in
`~/.config/OpenRGB`.

## Disk

Only the Kingston disk, selected by its `/dev/disk/by-id/` path in
`disk.nix`. The WD disk with Windows is never touched by disko.

| Partition | Contents |
|---|---|
| ESP, 512M | `/boot` (vfat, `umask=0077`) |
| LUKS (`cryptroot`), rest of the disk | btrfs with `@root`, `@nix`, `@persist`, `@games` (zstd compression, `noatime`) and `@swap` |

`@games` is mounted at `/games` and holds the Steam library
([0026](../decisions/0026-games-subvolume.md)). `@swap` holds a 16G
swapfile: tiki-rig suspends but doesn't hibernate, so it needn't match the
32G of RAM.

## Display

DP-3 on the left and DP-2 on the right, both 2560x1440 at 144 Hz and scale
1. Variable refresh rate is turned on for windows Umbriel identifies as
games, and stays off on the desktop.

## Windows

Windows 11 is on the WD disk with its own ESP. lanzaboote can't add boot
menu entries for another ESP, so Windows is started from the firmware's
boot menu: press **F8** at power on. **Del** opens the firmware setup. See
[0027](../decisions/0027-tiki-rig-windows.md).

## Before installing

These steps happen on the machine before the first install, in this order.
Enrolling our Secure Boot keys changes what BitLocker is sealed to, and
afterwards Windows Update can no longer change the firmware's keys itself.
lanzaboote enrols Microsoft's 2011 and 2023 certificates alongside ours
(from sbctl's bundled set), so Windows and the GPU's option ROM still load.

1. **Update Windows.** Boot Windows and install all updates, so its boot
   manager and the revocation list (`dbx`) are current before our keys go
   in.
2. **BitLocker.** In Windows, check whether the system drive is encrypted
   (Settings → Privacy & security → Device encryption, or `manage-bde
   -status`). Either turn it off, or save the recovery key somewhere off
   this machine.
3. **Update the BIOS.** fwupd doesn't support this board. Download the
   latest BIOS for the ROG Crosshair VIII Hero (Wi-Fi) from ASUS and flash
   it with EZ Flash in the firmware setup. The current one (4201, 2022)
   predates AMD's fix for fTPM stutter, which matters with TPM unlock on.
   Afterwards, check that Secure Boot is still off and the TPM enabled.
4. **Save work.** Push every repo under `~/repos`; several have unpushed
   commits or uncommitted changes (see #9).
5. **Back up game state** to external storage:
   - `~/.local/share/Steam/steamapps/compatdata` (Proton prefixes, holding
     saves for games without Steam Cloud)
   - `~/.local/share/RustyPathOfBuilding1` and `RustyPathOfBuilding2`
   - `~/.config/unity3d` and `~/.config/awakened-poe-trade`
6. **The Steam library.** Delete `steamapps/shadercache` first (about
   140G; Steam rebuilds it). Then either copy `~/.local/share/Steam` (about
   290G) to external storage and restore it into
   `/games/home/ballsten/.local/share/Steam` after install, or plan to
   re-download the games.

Then follow [Add a host](../howto/add-host.md) from step 1. The installer
partitions only the Kingston disk; check its ID with
`ls -l /dev/disk/by-id/ | grep nvme` before running disko.

After the first boots, as well as the checks in
[Install or reinstall a host](../howto/install-host.md#5-first-boot):

- Press F8 at power on and boot Windows with Secure Boot on.
- `sudo sbctl status` lists the Microsoft keys as enrolled.
- Both monitors run at 144 Hz (`umbriel outputs`).

## Firmware

ASUS AMI firmware: **Del** for setup, **F8** for the boot menu. Secure Boot
is under **Boot → Secure Boot → Key Management**. To put it into setup mode
for lanzaboote, delete only the platform key (PK). Don't clear all keys,
which also drops `dbx` ([Turn on Secure Boot](../howto/enable-secure-boot.md)).
